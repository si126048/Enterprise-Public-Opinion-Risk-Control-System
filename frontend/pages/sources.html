来源说明

数据来源

本系统演示数据来源于昆明市五华区基层治理场景的模拟样例，包括 12345 热线转办件、社区反馈、政务平台留言等渠道。数据仅用于课程演示，不代表真实事件。

采集方式

Phase 0-1 阶段采用 CSV 手工导入方式。系统支持通过 API 接口批量导入结构化数据，后续可扩展网页采集能力。当前版本不依赖实时爬虫，确保演示稳定性。

时间范围

样例数据覆盖 2024 年 6 月至 2025 年 3 月，涉及五华区下辖华山街道、护国街道、大观街道、丰宁街道、莲华街道、红云街道、龙翔街道、普吉街道、黑林铺街道、西翥街道等区域。

样本边界

本系统专注于昆明市五华区基层治理相关的民意诉求分析，不声称覆盖"全网实时监控"。数据样本有明确的地理和主题边界，分析结论仅对导入样本负责。

伦理与隐私说明

所有演示数据均为模拟生成，不涉及真实个人隐私。系统设计中，作者信息以哈希形式存储，不保留明文个人信息。AI 分析结果仅供辅助参考，不构成对任何个人或群体的评价或判断。

数据台账

所有数据来源记录保存于 source_ledger 表中，可通过 API 查询。每条记录保留原始来源 URL（如有）、采集时间、数据类型等元信息，确保可追溯。
